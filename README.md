# General IT & Technology Portfolio — GitHub Pages Starter

This is a no-build static website starter with a professional dark-blue theme. It includes sections for a profile photo, about, networking projects, cybersecurity/blockchain, administrative/virtual assistant work, skills, education/experience, contact links, and downloadable CV.

## Replace these placeholders before publishing
- `Your Name` / `YOUR NAME`
- The intro and About section with your accurate professional summary
- Education, training, experience and skills
- `your.email@example.com`
- `YOUR_USERNAME` in GitHub links
- `YOUR_LINKEDIN` in the LinkedIn link

## Files and folders
- `index.html` — homepage
- `assets/profile.jpg` — add your professional profile photo here
- `assets/cv.pdf` — add your CV PDF here
- `projects/networking/` — Packet Tracer `.pkt`, topology images and report
- `projects/cybersecurity-blockchain/` — project report and supporting files
- `projects/administrative-virtual-assistant/` — safe, non-confidential work samples

The example project links expect these files:
- `projects/networking/network-lab.pkt`
- `projects/networking/report.pdf`
- `projects/cybersecurity-blockchain/report.pdf`
- `projects/cybersecurity-blockchain/source.zip`
- `projects/administrative-virtual-assistant/sample.pdf`

If you do not have a file yet, remove its link from `index.html` or upload a file with the exact expected name. Project README files explain what to include.

## Publish with GitHub Pages
1. Sign in at https://github.com and create a **public** repository named exactly `YOUR_USERNAME.github.io`.
2. Upload `index.html`, `README.md`, and the `assets` and `projects` folders to the repository root. Do not upload the outer ZIP as your only website file; extract it first.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
5. Wait a few minutes and open `https://YOUR_USERNAME.github.io/`.

## Important privacy notes
A public GitHub Pages website is visible to anyone. Do not publish passwords, private keys, personal identification numbers, confidential employer/client files, or sensitive contact details. Check that CV and project documents are appropriate for public viewing. Keep individual files under GitHub's 100 MiB file limit; smaller `.pkt` files are recommended.
